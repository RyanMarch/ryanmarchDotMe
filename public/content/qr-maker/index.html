The Product

Finally, QR Codes with Personality

Most online QR code generators are bloated with ads, aggressive sign-up popups, and invasive tracking redirect links. As a Product Manager, I designed QR Maker to address this market gap: a clean, beautiful, and lightning-fast utility with a privacy-forward approach.

Beyond building a simple utility, this project was an exercise in end-to-end product delivery and technical stewardship. It provided an opportunity for me to conduct competitor analysis, build responsive layouts, use edge network infrastructure, write developer-focused user documentation, and deploy an automated API ecosystem that scales at zero marginal cost.

The privacy-first framework eliminates account setup bottlenecks and data liability. All computation happens locally on the user's device. The end result is a fast and delightful experience with endless customizations.

Custom Design Studio

Standard QR codes aren't known for pleasing aesthetics. To solve this, I built the custom design studio to act as place for users to build beautiful QR codes that match their needs:

  • Pixel Shapes: Users can swap standard square blocks for dots, rounded points, capsules, or connected grid lines.
  • Corner Markers: Adjust outer corner shapes to match your brand identity.
  • Custom Colors: Users can select from optimized preset palettes or define exact hex values for pixels and backgrounds, including transparency support.
  • Contrast Warnings: Real-time WCAG contrast validation proactively alerts users if a custom combination risks dropping below proper scan thresholds.

Input Types & Error Correction

Users can choose to encode standard URLs, plain text notes, Wi-Fi configurations, contact vCards, map coordinates, and calendar events.

Users can also overlay logos, brand icons, or emojis in the center. To make sure that the code is still easily scannable, the tool automatically raises the error correction level.

The API & Apple Shortcut

QR Maker also features an API for developers to integrate the tool into their own applications or workflows. The API is full-featured, well documented, and free to use. It delivers the same reliable QR code generation as the main app with the same lightning-fast response times.

Custom configurations are declared entirely via standard query parameters (controlling size, blocks, boundaries, and overlays). To lower developer friction, I treated documentation as a core product requirement. An interactive API playground featuring code examples, agent code generation tools, and validated Postman collections to expedite integration.

Apple Shortcut Integration

To prove the viability of the headless endpoint further extend the capabilities of the tool, I built and distributed an official Apple Shortcut companion.

This shortcut can take clipboard selections, highlighted text blocks, or structured contacts directly to the API, allowing users on iOS and macOS to generate QR codes natively via the platform Share Sheet right into existing workflows.

Architecture & Infrastructure

To keep the site highly reliable and free to run, I used a serverless, stateless architecture optimized for speed and performance:

  • Client-Side Computation: I run core compilation, rendering pipelines, and code generation logic in the user's browser, keeping with the goals of privacy and speed.
  • Share via URL: To achieve shareability without an active database layer, I add design variations directly into URL query parameters, paired with a system to reconstruct a shared design on the receiving end.
  • Service Worker Cache Strategy: Progressive Web App (PWA) workflows cache stylesheets, JavaScript modules, and fonts to achieve sub-second load times and support full offline creation.
  • Cloudinary Image Pipeline: Logo image uploads use an image CDN layer, returning an optimized asset which can then be sent to URL parameters for sharing.
  • Cloudflare Network Delivery: I deployed the site via Cloudflare infrastructure to guarantee high performance and worldwide availability.

Custom Tooling & Workflows

To support rapid iteration and maintain performance at scale, I developed custom utility tooling and structured local workflows:

  • Asset Optimization: Created automated image processing scripts to compress, resize, and convert screenshots and visual mockups into high-efficiency formats (like AVIF and WebP), keeping load times minimal.
  • Mockup & Video Production: Designed a workflow to capture and render device mockups and showcase videos, demonstrating touch mechanics and native app layouts.
  • Cloudflare & Mobile Testing: Configured local proxy routing to replicate Cloudflare Pages behavior and established physical device environments for debugging PWA behavior and native Share Sheet interactions.
  • Project Verification: Implemented regression tests to validate QR generation, accessibility, and API responses.

Product Outcomes & Lessons

Building QR Maker proved that complex client-side applications can run fast and reliably at scale. Combining edge caching with local browser execution kept the average Largest Contentful Paint (LCP) time measured in milliseconds. Storing the user's configuration entirely in the URL also showed that complex app states can be shared instantly without needing a database.

The biggest design challenge was balancing user customization (like custom logos and colors) with strict QR code scanning rules. Implementing real-time contrast checking and automated error correction keeps users from creating broken or unscannable codes, illustrating how automated validation can guide users toward success.
