The Product

TripDeck is a beautiful, easy-to-use, collaborative travel itinerary dashboard designed to make planning trips fast, flexible, and stress-free. It turns flight confirmations, train bookings, hotel reservations, and loose travel ideas into an organized, interactive timeline. As plans take shape, TripDeck automatically pulls in flight routes, train stations, venue addresses, and hourly weather forecasts. This keeps everything you need in one place, even when you are traveling offline.

Most travel apps use rigid, form-heavy tools that do not work for informal plans, or open-ended note apps that lack real-time utility. TripDeck provides the freedom of a scratchpad with the intelligence of a live travel dashboard.

TripDeck is built for privacy. Itineraries are encrypted directly on device so no one else can read them. You can build entire trips without creating an account. Work online and offline, and share itineraries with other travel companions.

Key Features

  • Dual-Pane Workspace: Edit itineraries using a visual drag-and-drop outline or a markdown editor. Changes in either pane update the other instantly.
  • Multi-Modal Transit & Flights: Enter a flight number or search train and transit lines to fetch routes, departure coordinates, terminal gates, and scheduled times.
  • Notes Board & Link Previews: Stage ideas, hotel options, and restaurant recommendations before scheduling. Web links generate rich previews, and saved notes can be searched and promoted onto the timeline with a click.
  • Interactive Route Map: Plots complete journeys including flight arcs, transit connections, accommodations, and scheduled stops with direct navigation links.
  • Multi-Currency Spend & Budget Tracking: Set spending limits, tag item costs, convert foreign currencies using European Central Bank rates, log general expenses, and export CSV reports.
  • Printable Pocket Guide: Generate a paper-friendly agenda or PDF with custom toggles for packing lists, confirmation codes, and a QR code linking to the live digital itinerary.
  • Traveler Utilities: Batch-shift entire trip dates forward or backward at once, monitor tight connection warnings between transit legs, use keyboard shortcuts for frequent actions, and save research via a browser bookmarklet.

Product Strategy

As the product manager and creator of TripDeck, I led the product from initial discovery through user experience design, system architecture, and launch.

  • User Problem Framing: Analyzed why travelers still rely heavily on spreadsheets and unstructured documents despite dozens of travel apps. Identified that people want structured travel plans that work both before and during their trip.
  • Frictionless Onboarding Strategy: Designed an instantly-accessible "Guest Mode" where users can immediately start typing or pasting plans without hitting a registration wall. Trip data saves directly to the browser, proving value before asking for user commitment.
  • Multi-Modal Transit Expansion: Extended itinerary intelligence beyond restaurants and activities to include flights, trains, subways, and public transit systems, creating a unified door-to-door journey planner.
  • Designing for the Travel Mindset: Structured the UI around high-stress travel moments: a Next Milestone countdown ticker, automatic timezone conversions, and offline accessibility for unreliable connectivity in transit.
  • Privacy by Design as a Value Proposition: Positioned user privacy as a central product pillar. By keeping user data encrypted on the client and supporting passkeys, TripDeck protects user data while eliminating backend data liability.

Technical Architecture

TripDeck is built as a lightweight web application designed for speed, portability, and zero-maintenance reliability:

  • Vanilla Web Stack: Built with native ES6 JavaScript modules, modern CSS custom properties, and semantic HTML without heavy frontend frameworks or bundling steps.
  • Serverless Cloudflare Backend: Deployed on Cloudflare with edge functions that securely retrieve real-time flight data, Transitland rail schedules, Google Places information, Mapbox GL maps, and Open-Meteo weather endpoints, complete with quota and cost tracking.
  • Resilient Flight & Venue Caching: A dual-provider flight engine uses AeroDataBox with automatic AirLabs fallback, backed by timetable caching in Cloudflare D1 so schedules remain accessible during network drops.
  • Client-Side End-to-End Encryption: Itinerary data is encrypted on device before syncing, deriving master keys from WebAuthn passkeys so server infrastructure never sees plaintext travel plans.
  • Offline Caching & Multi-User Merge: A Service Worker pre-caches application assets for offline travel. A three-way merge engine handles simultaneous edits cleanly across collaborator devices.

Learnings & Takeaways

Building TripDeck reinforced several key product principles: reducing friction upfront drives engagement, thoughtful defaults perform better than complex settings menus, and privacy can coexist with a collaborative user experience.

By treating travel planning as an iterative process supporting everything from flight confirmations to early research notes, TripDeck provides clarity when planning at home and confidence while on the move.
