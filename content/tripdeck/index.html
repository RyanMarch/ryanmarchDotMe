TripDeck

A local-first, end-to-end encrypted travel itinerary dashboard

Product Manager & Creator • 2026

The Product

TripDeck is a travel itinerary dashboard that organizes flight confirmations, hotel reservations, and notes into a clean, visual timeline. As users add trip details, TripDeck automatically populates flight schedules, addresses, hourly weather, and interactive map pins, while maintaining a real-time countdown to upcoming events.

Most itinerary tools force a choice between forms that don't fit unstructured plans, or unstructured notes apps that lack real-time utility. TripDeck combines the speed of plaintext editing with the organization of an interactive dashboard.

TripDeck is built with zero-knowledge encryption. 100% of data is encrypted end-to-end client-side. The app operates completely offline after initial load, and shared trips only expose what the creator explicitly chooses to share.

Features

  • Visual Builder & Markdown Editor: Edit itineraries using a drag-and-drop visual outline or a raw markdown editor. Both views remain synchronized in real time.
  • Flight & Location Lookup: Enter a flight number to automatically pull route details, schedules, and status.
  • Place Finding: Search hotels or venues to automatically import addresses and map coordinates.
  • Live Status HUD: Features a mechanical split-flap countdown ticker for the next scheduled event alongside current weather conditions.
  • Interactive Map View: Automatically plots airports, accommodations, reservations, and activities.
  • Contextual Packing Lists: Generates custom packing checklists based on trip destinations, dates, and forecasted weather, with support for saving custom templates.

  • Offline-First & PWA Support: Itineraries, gate numbers, and notes remain accessible offline without network connectivity.

My Role

As the sole product manager and creator of TripDeck, I directed the project through concept development, interaction design, security architecture, and client-side engineering.

  • Discovery & Problem Framing: Identified friction in existing tools used for travel (including spreadsheets) and found rigid data structures or no real-time utility. Scoped a flexible, text-based editor capable of structuring complex travel plans in a beautiful, usable layout.
  • Privacy & Account Architecture: Established client-side encryption as a core product requirement from day one. Designed passkey authentication to eliminate passwords and implemented instant guest mode access so users can build itineraries without creating an account.
  • UX & Interface Design: Designed a dual-pane interface keeping the visual drag-and-drop builder and raw markdown editor fully synchronized, allowing users to switch fluidly between typing and visual layout.
  • Security & Sharing System: Designed a cryptographic sharing architecture for read-only and collaboration links, as well as supporting link rotation.
  • Product Strategy & Roadmap: Phased development around a local-first core, ensuring complete offline functionality before layering cloud sync, passkey authentication, and further product expansion.

Technical Architecture

TripDeck is built as a modern progressive web app using native script modules, vanilla CSS, and HTML with no frameworks or bundlers. Serverless Cloudflare Functions securely proxy API endpoints (Mapbox GL, Open-Meteo weather forecasts, Google Places, and AirLabs flight status tracking) and interface with a Cloudflare D1 SQL database for encrypted storage.

The encryption architecture ensures complete user privacy. Account data is encrypted client-side prior to transmission, deriving encryption keys directly from the user's passkey. Shared trips utilize independent content keys wrapped with envelope encryption. Rotating share links invalidates previous access keys without affecting original trip data.

Offline capabilities are powered by a Service Worker caching strategy that pre-caches application assets, Mapbox GL components, and timezone libraries. Local-first storage guarantees that itineraries remain fully accessible and editable on the client device without network availability or account creation.

Outcomes & Impact

TripDeck demonstrates that privacy-first architecture and rich web experiences can deliver an easy-to-use product without compromising performance. By combining client-side encryption with passkey authentication, user itineraries remain completely unreadable to backend servers and eliminate password storage liabilities altogether.

From a user experience standpoint, pairing guest access with plaintext markdown editing created an efficient travel planning workflow. Users can convert unstructured confirmation emails into a clear timeline and interactive, sharable map in seconds, maintaining reliable offline access when traveling without cellular service.
