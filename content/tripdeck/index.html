The Product

TripDeck is a beautiful, easy-to-use, collaborative travel itinerary dashboard designed to make planning trips fast, flexible, and stress-free. It turns flight confirmations, train bookings, hotel reservations, and loose travel ideas into an organized, interactive timeline. As plans take shape, TripDeck automatically pulls in flight routes, train stations, venue addresses, and hourly weather forecasts. This keeps everything you need in one place, even when you are traveling offline.

Most travel apps use rigid, form-heavy tools that do not work for informal plans, or open-ended note apps that lack real-time utility. TripDeck provides the freedom of a scratchpad with the intelligence of a live travel dashboard.

TripDeck is built for privacy. Itineraries are encrypted directly on device so no one else can read them. You can build entire trips without creating an account. Work online and offline, and share itineraries with other travel companions.

Key Features

  • Dual-Pane Workspace: Edit itineraries using a visual drag-and-drop outline or a markdown editor. Changes in either pane update the other instantly.
  • Multi-Modal Transit & Flights: Type a flight number or search train and transit lines to fetch routes, departure coordinates, and scheduled times.
  • Find & Add Places: Search for hotels, restaurants, and sights to add. TripDeck fills in addresses, map pins, and local details.
  • Scheduled Events & Flexible Ideas: Organize time-bound events alongside unscheduled activities and a dedicated ideas scratchpad for things you might want to do later.
  • Interactive Route Map: Automatically plots your full journey including air routes, transit connections, accommodations, and activities.
  • Multi-Currency Spend & Budget Tracking: Set a trip spending limit, tag expenses directly on items (such as Cost: 120 EUR), convert foreign currencies to your preferred home currency automatically, record general expenses, and export CSV reports.
  • Printable Pocket Guide: Generate a paper-friendly agenda ready for print or PDF export. Customize it by including packing lists, and QR codes linking directly back to your live digital itinerary.

Admin Dashboard

To monitor usage, performance, and app behavior, TripDeck includes an internal administrative dashboard built to monitor platform health, manage runtime controls, and inspect real-time service operations:

  • Provider Usage & Cost Tracking: Live tracking monitors usage across maps, flight status services, weather endpoints, and geocoding APIs. Detailed request counts, success rates, and calculated monthly costs prevent unexpected billing spikes.
  • Runtime Feature Controls: System controls let administrators toggle feature flags, display global announcement banners, or toggle maintenance mode.
  • Role-Based Access: Administrative access is permission-based and requires passkey verification.
  • Help Center Telemetry: Anonymous search monitoring logs queries and zero-result questions, providing a direct signal on where documentation needs improvement.

Product Strategy

As the product manager and creator of TripDeck, I led the product from initial discovery through user experience design, system architecture, and launch.

  • User Problem Framing: Analyzed why travelers still rely heavily on spreadsheets and unstructured documents despite dozens of travel apps. Identified that people want structured travel plans that work both before and during their trip.
  • Frictionless Onboarding Strategy: Designed an instantly-accessible "Guest Mode" where users can immediately start typing or pasting plans without hitting a registration wall. Trip data saves directly to the browser, proving value before asking for user commitment.
  • Multi-Modal Transit Expansion: Extended itinerary intelligence beyond basic restaurants and activities to include flights, trains, subways, and public transit systems, creating a unified door-to-door journey planner.
  • Designing for the Travel Mindset: Structured the UI around high-stress travel moments: a Next Milestone countdown ticker, automatic timezone conversions, and offline accessibility for unreliable connectivity in transit.
  • Privacy by Design as a Value Proposition: Positioned user privacy as a central product pillar. By keeping user data encrypted on the client and supporting passkeys, TripDeck protects user data while eliminating backend data liability.

Technical Architecture

TripDeck is built as a modern web application designed for speed, portability, and zero-maintenance reliability:

  • Vanilla Web Stack: Built with native ES6 JavaScript modules, modern CSS custom properties, and semantic HTML operating without heavy frontend frameworks or compilation build steps.
  • Serverless Cloudflare Backend: Deployed on Cloudflare with lightweight functions that securely proxy real-time flight data, Transitland rail systems, Google Places, Mapbox GL maps, and Open-Meteo weather APIs.
  • Resilient Flight & Venue Data Caching: A dual-provider flight engine uses AeroDataBox with automatic AirLabs fallback, backed by timetable caching so flight routes and schedules stay accessible. Venue data is enriched with open hours, phone numbers, and links, all cached to keep external API costs low.
  • Client-Side End-to-End Encryption: Itinerary data is encrypted on the client device before syncing to cloud storage (Cloudflare D1), deriving master keys directly from WebAuthn passkeys so that server infrastructure never sees raw travel details.
  • Offline Caching & Multi-User Merge: A Service Worker pre-caches application assets for offline travel. When planning with others, a three-way merge engine handles simultaneous edits cleanly across devices without overwriting collaborator updates.

Learnings & Takeaways

Building TripDeck reinforced several key product principles: reducing friction upfront drives engagement, thoughtful defaults perform better than complex settings menus, and privacy can coexist with a collaborative user experience.

By treating travel planning as an iterative process supporting everything from flight confirmations to half-formed itinerary ideas, TripDeck provides travelers with clarity when planning at home and confidence while on the move.
