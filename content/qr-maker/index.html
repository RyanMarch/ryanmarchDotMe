The Product

Finally, QR Codes with Personality

Most online QR code generators are bloated with ads, aggressive sign-up popups, and invasive tracking redirect links. QR Maker is a clean, fast, and beautiful alternative that is lightning fast and runs entirely locally, so there are no tracking cookies or ad networks.

Beyond building a simple utility, this project was a playground to keep my product management and technical skills sharp. It gave me an opportunity to design responsive layouts, explore Cloudflare infrastructure, write user documentation and API docs, and deliver a stable, production-ready product.

QR Maker is a simple, tool to build custom-styled QR codes. There are no accounts to set up, no subscription fees, and it's built with a privacy-first mindset. All QR generation and customizations are performed locally on device, ensuring all inputs remain private.

Custom Design Studio

QR codes aren't know for being very aesthetic. The custom editor in QR maker lets users match a brand style or their own personality:

  • Pixel Shapes: Swap standard square blocks for dots, rounded points, capsules, or connected grid lines.
  • Corner Markers: Multiple shapes for the outer corner markers.
  • Custom Colors: Select from preset or custom colors for the pixels and background. Set solid background colors or go fully transparent.
  • Contrast Warnings: Analyzes the contrast ratio between elements and warns the user if the layout could be hard to scan.

Input Types & Branding

The interface supports standard inputs like URLs, plain text notes, Wi-Fi credentials, and contact cards.

Users can also overlay logos, brand icons, or emojis in the center. To make sure this doesn't break the code, the tool automatically raises the error correction level.

The API & Apple Shortcut

QR Maker also features a developer API for those who want to integrate the tool into their own applications or workflows. The API is full-featured, well documented, and free to use. It is built with a privacy-first mindset. It delivers the same reliable QR code generation as the main app with the same lightning-fast response times.

The companion API generates customized codes on the fly using standard query parameters (like content, size, colors, and icon overlays). To make sure the product was truly stable, I also built and hosted interactive API documentation, complete with a request playground, code generators, and Postman collections.

Proof of Concept: Apple Shortcut

To prove the API worked in the real world and to learn how to build and distribute native iOS integrations, I built a custom Apple Shortcut.

Users can highlight text, links, or contact info anywhere on macOS or iOS, call the API in the background, and customize their QR code instantly via the system Share Sheet.

Architecture & Infrastructure

Delivering a stable, lightning-fast product required a architecture that doesn't rely on databases or server backends:

  • Client-Side Engine: QR code compiling and canvas drawing are handled entirely in the browser. This keeps the application fast and privacy-first, since user data is processed locally.
  • Decoupled State: Because there is no database backing, user designs are saved and shared by encoding their design directly into the URL query parameters.
  • Offline PWA Support: Service workers cache core CSS, JS, and font assets so the application launches instantly and works offline.
  • Cloudinary Integration: To keep shared URLs functional when users upload custom logo files, the app uploads images to Cloudinary and embeds the remote image URL in the shared link.
  • Infrastructure & Analytics: Deployed via Cloudflare to leverage edge-network caching, with Cloudflare Web Analytics enabled to monitor performance and traffic.
