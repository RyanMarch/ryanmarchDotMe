FileNamer

Build naming conventions and bulk rename files locally

Product Manager & Creator • 2026

The Product

FileNamer is a lightweight, local-first web utility for designing standardized naming templates and batch renaming files directly in the browser. It is designed for professionals and teams who need to maintain strict, structured guidelines for document and media file naming.

Professionals need reliable ways to structure files without relying on complex scripting or risking data privacy. Uploading sensitive project files to remote servers for processing presents a security liability, while manual renaming is tedious and prone to formatting errors.

To address this, I built a privacy-first application prioritizing native browser tools and lightweight web assets. All processing occurs locally without external scripts.

The template selector, field builder, and output preview.

Features

  • Drag-and-drop Field Builder: Compose naming templates from reusable field types: free text, dates (with format tokens like YYYY-MM-DD), auto-incrementing counters, and fixed separators. Fields can be reordered and removed at any time.
  • Live Output Preview: As fields are configured, a real-time preview renders the exact filename that will be produced, giving users immediate feedback before any files are touched.
  • Bulk Edit Grid: Drop files onto the grid to queue them for renaming. Each row exposes per-file overrides for dynamic fields, and columns can be filled down or imported from a CSV for large batches.
  • CSV Import / Export: Teams can maintain naming metadata in a spreadsheet and import it directly, then export the completed mapping as a reference after processing.
  • Local File System Rename: Files are renamed entirely in the browser using the File System Access API. There are no uploads or server round-trips; no data ever leaves the device.
  • ZIP Download Fallback: Where the File System Access API is unsupported, renamed files are packaged into a ZIP archive for manual download to preserve privacy.
  • Shareable Templates via URL: Template configurations are serialized into the URL hash, allowing users to share a fully configured template as a single link without account or databases.
  • Offline PWA Support: A Service Worker caches all assets, enabling the tool to load and operate without a network connection after the first visit.
  • Help Center: Integrated in-app documentation covers the full workflow, including template management, bulk renaming, and sharing guides.

My Role

I served as the sole product manager and creator on FileNamer, responsible for the product lifecycle from initial discovery through ongoing iteration.

  • Discovery & Problem Framing: Identified the gap through firsthand friction managing large media libraries. Reviewed existing options such as command-line tools and server-based apps and determined they created either a technical barrier for non-developer users or a privacy risk for enterprise users. Worked directly with users to understand their existing workflows and pain points for naming files.
  • Product Decisions: Prioritized a no-install, zero-dependency approach. Shipping a static web app allows for wide reach and eliminates update friction. URL-based template sharing provided a sharing feature without backend infrastructure.
  • UX & Interaction Design: Designed the drag-and-drop field builder interaction model to make template composition approachable for non-technical users, while providing the funcitonality needed by operations and production teams who manage thousands of files.
  • Roadmap & Prioritization: Scoped the initial release around the core build and preview workflow. Introduced the Bulk Edit Grid, CSV import, and subsequent interface iterations based on user feedback.
  • Documentation: Authored the product's Help Center, structuring content around the key jobs users needed to accomplish rather than feature-by-feature documentation.

Outcomes & Impact

FileNamer enables users to safely package renamed files into a .zip archive. All processing happens locally, guaranteeing files never leave their device.

Leveraging Service Worker caching for offline support and encoding template rules directly into the URL, the tool delivers an accessible, database-free sharing experience.

With extensive user documentation, FileNamer is easy to use for users of all experience levels. The included templates allow for all kinds of needs to be met right away, and easily encourage users to pick up the field builder and create their own custom templates.
